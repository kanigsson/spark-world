# Verified (or not) SPARK code and tools

This repository contains a loose collection of SPARK code, tools, and experiments
at various stages of completion. A more or less complete list:

## Tools

- apps/fuzzy: A fuzzy matcher that can be used as a replacement for fzf
- apps/git_view: a git history viewer
- apps/spark_re: A regex implementation with tools spark-rg and spark-grep
- apps/spark_diff: A differ tool
- apps/inflate: A decompression tool

## Libraries

- git_changes: A library to access git information
- json: json parser
- ore: grab-bag utilities
- tui: TUI helpers
- unicode_text: A unicode string library

## Experiments

- BWT: implementation and complete proof of Burrows-Wheeler transform, including
       bijective form.
